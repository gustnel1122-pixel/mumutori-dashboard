# 무무토리 ERP

무무토리의 상품, 통장 자금, 매입·원가, 매출·수금, 입출고·실사를 기록하는 정적 웹 애플리케이션입니다.

- 상품과 원장은 등록·수정 창에서 저장합니다. 상품 사진, 판매 상태, 가격, 바코드, 안전재고를 관리할 수 있습니다.
- 김현수·백다희 명의 입금은 자금 충전 또는 대여금 회수로 관리하며 매출에 포함하지 않습니다. 짝이 확인된 내부 계좌이체는 보존합니다.
- 매출 기록과 통장 입금은 별개입니다. 매출 수금·채널 정산 입금만 매출에 연결할 수 있습니다.
- 최초 실사로 재고 기준을 정하고 입고·출고·반품·폐기·창고 이동을 누적합니다. 과거 사입량으로 현재 재고를 추정하지 않습니다.
- 매입·매출과 입출고를 연결할 수 있으며 문서 수량 초과, 중복 수금 연결, 실사 이후 음수 재고를 막습니다.
- 거래 취소는 원본을 보존하고 변경 이력을 남깁니다. 취소 포함 필터에서 복구할 수 있습니다.
- CSV 미리보기·중복 후보 제외, JSON 전체 백업·병합, 병합 전 복사본을 제공합니다.

## 저장

데이터는 **현재 브라우저의 localStorage**(`mumutori-private-finance-v3`)에 저장됩니다. 서버 저장, 계좌 자동 수집, 기기 간 동기화는 연결되어 있지 않습니다. 기존 자료와 알 수 없는 원본 필드는 보존합니다. 브라우저 저장 자료가 있을 때 ERP 전환 전 복사본을 남깁니다. 다른 탭에서 변경되면 오래된 화면의 덮어쓰기를 막습니다.

전체 백업을 내려받아 보관하세요. 기존 공개 초기 자료는 그대로 유지하며, 화면에서 입력한 자료는 저장소에 업로드되지 않습니다. 금융 원장은 보유 자료 범위에 한정되며 실시간 은행 잔액으로 표시하지 않습니다.

## 부서별 독립 페이지

운영 홈, 재무, 자금, 상품, 구매·원가, 판매·정산, 물류·재고, 거래처, 변경 이력, 설정·백업의 10개 실제 주소를 사용합니다. 각 페이지는 `src/pages`의 해당 모듈만 불러오며 공통 원장을 공유합니다. 상품·문서별 링크로 관련 부서의 원장을 이어 볼 수 있습니다.

자세한 책임 범위, 공통 데이터 계약, 다음 개발 후보와 저장 확장 계획은 [부서별 설계](docs/DEPARTMENTS.md)를 참고하세요.

## 개발

`src/erp-core.js`는 원장 검증·계산, `src/store.js`는 저장, `src/erp-app.js`는 공통 UI·수정 창, `src/pages/*.js`는 부서 화면입니다. 외부 런타임 라이브러리는 없습니다. 최신 Chrome/Edge에서 실행합니다.

```sh
python build.py
node tests/core.test.js
ERP_CHROME=/path/to/chromium node tests/ui.test.js
ERP_CHROME=/path/to/chromium node tests/pages.test.js
```

`build.py`는 각 HTML 진입점과 콘텐츠 버전을 생성합니다. `data/seed.json.gz`는 기존 공개 초기 자료입니다. 로컬에 추출된 `data/seed.json`이 있을 때만 같은 데이터를 다시 압축하며, 새 개인 원장으로 교체해서는 안 됩니다.

브라우저 테스트에는 Playwright와 Chromium이 필요합니다. 격리된 가상 주소에서 실제 파일을 제공하므로 운영 장부를 변경하지 않습니다. 10개 직접 진입, 해당 페이지 모듈만 로딩, 상품별 연결과 뒤로 가기, 여러 탭 반영과 열린 초안 보호, 기존 저장 키·필드 보존, 1,200개 상품의 25행 페이지네이션, 모바일/태블릿, 동작 줄이기를 검증합니다.

페이지 분리로 다른 부서 화면의 코드와 DOM을 함께 만들지 않습니다. 저장은 여전히 전체 JSON localStorage이므로 대용량 부분 조회와 기기 간 동기화는 후속 단계입니다.

## 업무 기준

- 미확인 원가는 빈칸으로 보존합니다. 0은 실제 비용이 없는 경우입니다.
- 배부단가는 참고값입니다. 전 품목의 원화 금액, 기존 위안 금액, 또는 수량의 같은 기준으로 구매비·통관비를 배부하며 배송비는 수량 기준으로 배부합니다. 일부 품목만 금액이 있거나 통화 기준이 혼합되면 단가를 미확정으로 둡니다.
- 부가세 공제액은 증빙으로 확인한 금액을 직접 입력합니다. 자동 세금 신고나 세금계산서 발행 기능은 없습니다.
- 동일 날짜 실사·입출고는 등록 순서로 계산합니다. 실사를 다시 등록하면 그 시점의 기준 수량을 새로 정합니다.
