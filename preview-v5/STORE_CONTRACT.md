# 상품 관리 미리보기 자료 경계

이 폴더의 `createMemoryStore`는 가상 자료만 다루며, 새로고침하면 변경이 사라집니다. 실제 장부나 네트워크에는 접근하지 않습니다. 화면은 아래 비동기 인터페이스를 사용합니다.

| 메서드 | 동작 |
| --- | --- |
| `load()` | 상품, 부자재, 세트의 새 스냅샷 반환 |
| `saveProductLinks(productId, links)` | 등록된 부자재 연결만 검증하고 반영 |
| `saveReceipt(productId, index, receipt)` | 입고 기록 추가·수정; 날짜·차수·수량·금액·1688 링크 검증 |
| `saveImage(productId, dataUrl)` | 1MB 이하 PNG·JPG·WebP를 메모리에만 보관 |
| `createMaterial(material)` | 부자재 등록; 박스는 거부 |
| `saveMaterial(id, fields)` | 기존 부자재의 통화·단가 등을 수정하며 미편집 필드 보존 |
| `createSet(set)` | 등록된 상품과 포장 부자재를 확인해 세트 등록 |

운영 연결을 위해서는 기존 상품 v4의 서버 인증·계정 전환 시 데이터 초기화·상품별 조건부 저장을 유지하는 별도 저장 어댑터가 필요합니다. 상품의 입고 이력, 판매가 상태, 부자재 참조 및 세트 구성과 기존 상품 ID의 매핑, 새 부자재·세트 저장 위치와 권한 규칙, 동시 수정 시 충돌 안내, 기존 출고 경로와 연결하는 책임 경계를 먼저 확정해야 합니다. 현재 어댑터는 인증, 영구 저장, 운영 규칙 검증 또는 실제 장부 쓰기를 수행하지 않습니다.

이 단계에서는 박스와 판매 수량 연동을 구현하지 않습니다. 입고 기록 편집과 누끼 사진 선택은 가상 자료의 메모리에서만 동작합니다. 실제 입고 자료 이전이나 누끼 창고 연결은 이 미리보기에 포함되지 않았습니다. 사진은 브라우저 밖으로 전송하지 않습니다.
