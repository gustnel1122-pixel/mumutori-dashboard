# 라벨·가격표의 색상과 모양 묶음

`catalog-groups.json`은 페이지에서 보이는 이름과 묶음의 구성 상품 ID만 정한다. 상품홈 이름·바코드·재고·매장가를 저장하거나 합치지 않는다. 같은 인증 GET 결과를 라벨/가격표가 공유하며 `catalog-groups.mjs`에서 묶음 행을 만든다. 유사한 글자가 있다는 이유로 자동 통합하지 않는다. 명시된 상품 ID만 포함한다.

확인된9개는 행운의 거북이?5종, 거위 집게핀5종, 거위 키링5종, 마늘새3색, 카피바라 인형3종, 북극3종, 햄스터3색, 떡메모지2디자인, 바코드가 있는 엽서7디자인이다. 바코드 없는 성원 엽서 원래 항목은 엽서7디자인과의 관계를 확인하기 전 별도로 둔다. 서로 다른 바게트와 1/2차 감자 셰프·억울버섯도 합치지 않는다.

라벨은 묶음 행을 누르면 색깔/모양 선택을 연다. 선택하기 전 기존 입력을 비워 이전 상품의 바코드를 잘못 쓰지 않게 한다. 각 구성원의 기존 바코드·재질·원산지와 품명을 그대로 입력한다. 거북이5종 품명은 11/19 2258 v2 PDF와 라벨 입력표를 확인해 `labels-specs.json`에 보존했다. 거위 색 이름이 기록에 없으면 바코드로 선택한다. `커위키링` 원문도 라벨에서 고치지 않는다.

가격표는 묶음 ID를 한 상품으로 사용해 한 장만 담긴다. 각 구성원의 최신 GET 매장가를 대조하고 다르거나 미입력인 값이 있으면 숫자를 비운다. 다른 가격은 빨간 ‘가격 다름’, 누락은 ‘매장가 미입력’으로 표시한다. 직접 숫자를 적은 후에 담을 수 있다. 색 하나의 가격을 임의의 공용 값으로 고르지 않는다. 같은 묶음이 카드/스티커 모두에 담기면 기존 중복 모양 검증으로 막는다.

거북이·거위는 11/19 2125와 v2의500원 존 근거가 있는 군이며, 현재 구성원 매장가가 모두500원일 때 스티커, 그 밖은 카드로 제안한다. 기존 마늘새·북극3종의 스티커와 다른40종 기준은 유지한다. 기존 v3d의 사장님21:09 공용 가격은 매장가가 서로 같음을 확인한 뒤 우선 적용한다. 그래서 아직 옛 매장가2,000원이 남은 북극3종도 정본의3,000원으로 유지한다. 구성원 가격이 다르면 이 우선값도 자동 적용하지 않고 사람이 적게 한다.

햄스터는 아직 바코드·재질·원산지·매장가가 없어 라벨/PDF 검증을 통과하지 못한다. 묶음 표시를 추가했다고 새 바코드를 만들거나 인쇄 정보를 추측하지 않는다. 확인 필요8건은 설정의 `review`와 공식 결과에서 구분한다.

검수는 `tests/catalog-groups.test.cjs`, 기존 라벨/가격표 시험, 실제 페이지를 통한 거북이 분홍1칸·공용 가격표1개, 2130의116칸 PDF와 v3d10개 PDF 비교로 수행한다. 116칸의 빼꼼/컴퍼니는 ‘떡메모지’ 묶음에서 각각 원래 바코드를 선택한다. 그리기 Worker·글꼴·보정·원본 벡터 도안은 변경하지 않는다.
