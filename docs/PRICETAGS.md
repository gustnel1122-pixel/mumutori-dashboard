# 가격표 탭

`labels.html`의 라벨 / 가격표 탭은 같은 Google 로그인과 같은 읽기 전용 상품 목록을 사용한다. `labels-core.mjs`에서 라벨 필드, 원래 상품명, `sale.storePrice` 숫자만 전달한다. 원가·입고·구매 내역은 전달하지 않는다. 가격표의 수정값·담은 목록은 메모리에만 있고 서버·브라우저 저장소에 쓰지 않는다.

`pricetags-rules.json`은 11/18·11/19 모양 기준40종, 오늘 v3d의 가격표 이름, 영어20개와2215 수정2개, 사장님21:09 가격을 담는다. 목록 밖 영어는 빈칸이다. 별도 번역을 만들지 않는다. 규칙의 가격이 없으면 로그인해 읽은 상품홈 매장가를 사용한다. 상품 이름과 가격표 이름이 다르면 화면에 원래 상품 이름을 함께 보여 준다. 무무바게트20000578과 무무왕바게트20000172는 서로 다른 ID·바코드로 유지한다.

카드와 스티커에 같은 상품 ID를 모두 담으면 빨강으로 표시하고 내보내기를 차단한다. 한 모양의 같은 상품을 다시 담으면 그 항목만 수정한다. 잘못된 가격·긴 문구·지원하지 않는 글자는 오류로 알린다. 기본 영어가 없는 상품은 영어 줄 없이 출력할 수 있고 직접 적을 수도 있다.

## 출력

카드85×55mm, 아래10mm 비움, 뒷면 같은 자리 원본 로고. 스티커60×38.823529mm(정본38.8 표기), 가운데 정렬. 크림RGB250/245/229, 밤색104/35/1, PoorStory 정본 글꼴이다. 카드10개/A4, 스티커18개/A4로 이어지고 남는 뒷면 칸에는 로고를 넣지 않는다. PDF 앞면·뒷면·스티커를 따로 내려받는다. PDF.js 미리보기는 내려받는 PDF의 같은 바이트를 사용한다.

브라우저 Worker의 Pyodide0.29.0에서 ReportLab5.1.0·pdfrw0.4·fonttools를 실행한다. `assets/pricetags`에 design3d v3d 정본의 도안·PoorStory·글꼴 라이선스·출처 해시를 보관한다. v3d10개 기본값은 변경 없이 보존한 원본 벡터 폼을 사용한다. 수정한 문구는 원본 v3b의 글꼴·크기·기준선·가운데 계산을 적용하며, 스티커는 실제 글자 윤곽과 로고 범위로 위아래를 맞춘다. 배경·로고를 새 그림으로 대체하지 않는다.

인쇄: 엡손L18050, A4, 실제크기100%, 여백없음 해제. 카드는 앞면을 인쇄한 종이를 뒤집어 대응하는 뒷면 쪽을 인쇄한다. 실제 인쇄 작업을 자동 실행하거나 재고를 줄이지 않는다.

## 검수

`node --test tests/pricetags.test.cjs tests/labels.test.cjs`로 바게트 분리·가격 우선순위·수정 이름·목록 밖 영어·중복 모양·로컬 수정·원가 제거 및 기존 라벨 동작을 확인한다. 최종 전체 시험과 build.py, main push, Pages built를 별도로 확인한다. v3d10개는 브라우저에서 만든3개 PDF를 원본과 렌더링·텍스트·좌표로 비교한다. 로컬 fixture 캡처와 운영 로그인 뒤 실물 상품 검수는 결과 문서에 구분한다.
